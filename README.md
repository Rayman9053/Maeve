# Startup Opportunity Map

A taxonomy of markets where someone could start a company, organized into 8 pillars:
Health & Wellness, Care & Conditions, Wealth, Relationships, Mind/Meaning & Growth,
Lifestyle/Home & Experiences, Enterprise & AI, and Planet & Frontier.

`taxonomy.yaml` is the **single source of truth**. Every other file under `output/` is generated from it.

## Quick start

```bash
pip install -r requirements.txt      # PyYAML
make                                 # validate + build everything (same as the two commands below)
python3 scripts/validate.py --strict
python3 scripts/build.py             # needs Node 18+ (npx) for the HTML; use --no-html to skip
```

## Node schema

```yaml
- name: GLP-1 economy              # required, 1-4 words (excluding "&"), unique among siblings
  note: "Short scope/caveat/examples (as of 2026)."   # optional
  tags: [trending, regulated]      # optional: trending, underserved, regulated, b2b, consumer, ai-native
  see: ["Pillar > Category > Subcategory > Leaf"]     # optional exact-path cross-references
  children: [...]                  # optional
```

Rules the validator enforces:
- The YAML parses; only the keys above are allowed.
- Sibling names are unique (case-insensitive).
- Max depth is 4: Pillar › Category › Subcategory › Leaf. If a leaf needs children, promote it or split it.
- Every non-leaf has 3–8 children.
- Names are ≤ 4 words and contain no emoji or `[tags]`. Markers are rendered from `tags`.
- Tags come from the vocabulary above. A tag covers its whole subtree, so descendants must not repeat it. `b2b` and `consumer` can't both be on one node.
- Every `see:` path resolves to exactly one node and doesn't point at the node itself or one of its ancestors.

`--strict` also fails on warnings: the same name appearing in two places, a category mixing subcategories that do and don't have leaves, and notes over 200 characters.

**Placement rules** (where a topic lives when it could fit two places):
- financial products → Wealth (all insurance lines included)
- clinical → Health & Wellness / Care & Conditions
- relational → Relationships
- consumer spending → Lifestyle
- horizontal B2B software → Enterprise & AI
- physical-world and deep tech → Planet & Frontier

Keep the topic once and add a `see:` in the other place.

**Tag criteria:**
- `trending`: a clear 2024–26 funding or adoption inflection, not merely "growing"
- `regulated`: needs licensing, clearance, or carries notable legal exposure
- `underserved`: obvious unmet demand

## Iterating (the repeatable loop)

```bash
cp taxonomy.yaml source/taxonomy-v2.yaml        # 1. snapshot the version you're about to change
$EDITOR taxonomy.yaml                            # 2. edit
python3 scripts/validate.py --strict             # 3. fix until clean
#                                                  4. add a "## v3" section to reports/changelog.md
#                                                     (backtick the before/after names) and log cuts in reports/cut.md
python3 scripts/reconcile.py source/taxonomy-v2.yaml        # 5. must report UNACCOUNTED: 0
python3 scripts/reconcile.py source/taxonomy-v2.yaml --write-additions v3   # list new nodes between the
#                                                     <!-- ADDITIONS:v3:START/END --> markers; never rerun old labels
python3 scripts/build.py                         # 6. regenerate outputs
```

`reconcile.py` matches names against every backticked name anywhere in `changelog.md` and `cut.md`.
A name logged in an earlier version therefore still counts, so keep names specific.

## Conventions

- Node names: 1–4 words, precise, sentence case below the category level, no filler. Don't repeat the parent's word unless it's a term of art ("Sleep apnea").
- Disambiguate names that could mean two things ("Athletic recovery" vs "Addiction recovery").
- Keep notes short. Brand examples go in notes as "e.g. X" and are as of 2026; verify before relying on them.
- Medical, legal and regulatory caveats are flags to check, not advice.
- Wording stays inclusive and viewpoint-neutral. Per the v1 decisions, cannabis/CBD, abortion services, relationship structures and sports betting/prediction markets are deliberately excluded.
